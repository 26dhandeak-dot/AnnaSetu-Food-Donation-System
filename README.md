# AnnaSetu – Food Donation Management System

A responsive front-end mini project built with HTML5, Bootstrap 5, CSS3 and JavaScript.

## Run locally
1. Download and extract the project.
2. Open `index.html` in a browser. Internet is required for Bootstrap CDN, icons, Google Fonts and remote sample photos.
3. Try the donation form, search/filter, pickup request buttons, demo login/register and pickup tracking status.

## Features
- Responsive landing page
- Food donation form with required-field validation
- Sample available donations with search and category filters
- Demo pickup request interaction
- Pickup status timeline
- Impact statistics
- Demo login and registration modals

## Important
This is a front-end demonstration. It does not include a real backend, database, authentication, live map, or actual donation/pickup service. Sample figures and listings are illustrative.

## Technologies
HTML5, Bootstrap 5.3, Bootstrap Icons, CSS3, JavaScript.
